== Description ==
Material AI is an FSE (Full Site Editing) WordPress theme built entirely with blocks and patterns. It provides a true visual editing experience in WordPress, allowing you to easily customize your website without coding. This multipurpose theme is suitable for business websites, agencies, portfolios, blogs, and other professional websites. No extra plugins are required with the theme, helping your website run smoothly and efficiently. Material AI includes multiple style variations, allowing you to quickly switch between different color schemes and visual styles. The free version includes 11 professionally designed patterns that you can use to build beautiful page layouts. With the WordPress Site Editor, you can easily manage various aspects of your website, including colors, typography, spacing, layouts, and styles. The Material AI Pro version comes with many additional blocks and professionally designed patterns, organized page-wise as showcased in our demo. It provides more design options and flexibility for creating complete websites. Checkout Pro Demo: https://nayrathemes.com/demo/pro/materialai/

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme, choose the theme's .zip file and click Install Now.
3. Click Activate to use your new theme right away.
4. Go to Appearance > Editor to customise templates, template parts and patterns.
