Material Energy is a child theme of Material AI. It replaces the header and the
main banner with an energy-style layout and recolours the palette in green and
deep navy.

== Description ==

Material Energy is an FSE (Full Site Editing) WordPress theme built entirely with blocks and patterns. It provides a true visual editing experience in WordPress, allowing you to easily customize your website without coding. This multipurpose theme is suitable for business websites, agencies, portfolios, blogs, and other professional websites. No extra plugins are required with the theme, helping your website run smoothly and efficiently. Material Energy includes multiple style variations, allowing you to quickly switch between different color schemes and visual styles. The free version includes 11 professionally designed patterns that you can use to build beautiful page layouts. With the WordPress Site Editor, you can easily manage various aspects of your website, including colors, typography, spacing, layouts, and styles. The Material Energy Pro version comes with many additional blocks and professionally designed patterns, organized page-wise as showcased in our demo. It provides more design options and flexibility for creating complete websites. Checkout Pro Demo: https://nayrathemes.com/demo/pro/material-energy/

== Installation ==

1. Install and keep the Material AI parent theme in wp-content/themes. It does
   not need to be activated.
2. Upload Material Energy through Appearance > Themes > Add New > Upload Theme.
3. Activate it.

== Frequently Asked Questions ==

= Do I still get the parent's style variations? =

Yes. Every colour in this theme resolves through the palette in theme.json,
with no colour literals in the stylesheet, so the variations that ship with
Material AI still recolour the header and the banner.

= Why does the child theme.json repeat the whole palette? =

A child theme's theme.json settings replace the parent's rather than merging
into them, so the full palette has to be present for the presets that are not
being changed to survive.
